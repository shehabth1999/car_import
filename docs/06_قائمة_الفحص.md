# 6. قائمة الفحص الكامل — أسئلة ومهام

دي اللي تعملها **بنفسك** على `khaled-test.genie-erp.com` عشان تتأكد إن السيستم
شغال، ومش مضطر تصدّق حد.

**طريقة الاستخدام:** كل مهمة فيها: تعمل إيه، تتوقع تشوف إيه، وخانة تعلّم فيها.
لو النتيجة مختلفة — **ده اكتشاف، مش فشل**. سجّله في آخر الملف.

**قبل ما تبدأ:** اعمل صفقة تجربة خاصة بيك وسمّيها باسم يبان (مثلاً عميل اسمه
"فحص — اسمك"). متجربش على صفقة حقيقية.

---

## أ. الأساسيات — إن السيستم أصلاً موجود

| # | المهمة | المتوقع | ✅ |
|---|---|---|---|
| A1 | ادخل السيستم وافتح قايمة التطبيقات | تلاقي تطبيق **Car Import** | ☐ |
| A2 | افتح Car Import | القوايم: Dashboard / Deals / Cars / Supplier listings / Documents / Initiatives / Call recordings / Message log / Configuration | ☐ |
| A3 | افتح Deals | كانبان فيه أعمدة بأسماء المراحل بالعربي | ☐ |
| A4 | عدّ الأعمدة | **14 عمود** | ☐ |
| A5 | Configuration → Stages and messages | 14 سطر، وكل واحد **Notify customer = مقفول** | ☐ |
| A6 | افتح أي مرحلة | فيها نص رسالة بالعربي جاهز | ☐ |

**أسئلة تجاوب عليها بنفسك:**
- ترتيب المراحل ده هو الترتيب الحقيقي في الشركة؟
- في مرحلة ناقصة أو زيادة؟
- أسماء المراحل هي اللي الموظفين بيستخدموها فعلاً ولا في أسماء تانية؟

## ب. الصفقة — دورة حياة كاملة

| # | المهمة | المتوقع | ✅ |
|---|---|---|---|
| B1 | Deals → Create → اختار عميل → احفظ | **Reference** اتملى لوحده بصيغة `KA/2026/xxxx` | ☐ |
| B2 | بصّ على Current stage و In this stage since | أول مرحلة + تاريخ ووقت النهاردة | ☐ |
| B3 | افتح Message log | سطر جديد للصفقة دي | ☐ |

| B5 | Message log تاني | سطر تاني، وحالة الإرسال **skipped** (لأن الرسايل مقفولة) | ☐ |
| B6 | ارجع للكانبان واسحب الكارت لعمود تاني | الكارت اتحرك، وفي سطر جديد في السجل | ☐ |

| B9 | دوس **Cancel** | الحالة بقت ملغية | ☐ |

**أسئلة:**
- ترقيم `KA/2026/0001` مناسب؟ ولا الشركة ليها نظام ترقيم تاني؟
- في حاجة تانية المفروض تمنع تحريك المرحلة غير "متوقفة" و"ملغية"؟

## د. رسايل العملاء — الأربع طبقات

| # | المهمة | المتوقع | ✅ |
|---|---|---|---|
| D1 | Stages → افتح مرحلة → افتح **Notify customer** → احفظ | المفتاح اتفتح للمرحلة دي بس | ☐ |
| D2 | حرّك صفقة **تجربة** للمرحلة دي | السجل يقول **sent** (أو fallback حسب القناة) | ☐ |
| D3 | على الصفقة: افتح **Hold customer messages** وحرّكها لمرحلة مفتوحة | السجل يقول **skipped** | ☐ |
| D4 | Config Parameters → `car_import.stage_messages_enabled` = `0` | أي حركة بعد كده → skipped مهما كانت المفاتيح | ☐ |
| D5 | ارجع المفتاح العام زي ما كان، وارجع المرحلة مقفولة | الوضع الآمن رجع | ☐ |

> ⚠️ اعمل الفحص ده على **عميل تجربة برقمك انت**، مش على عميل حقيقي.

**أسئلة:**
- نص الرسالة في كل مرحلة هو اللي الإدارة موافقة عليه؟
- في مراحل المفروض **متبعتش** رسالة أبداً؟
- مين المسؤول عن اعتماد قوالب واتساب، وامتى هيبدأ؟

## ط. أسئلة للإدارة (مش مهام تقنية)

1. **الرسايل:** مين بيعتمد صياغة رسايل المراحل الـ14؟ وامتى؟
2. **قوالب واتساب:** مين هيقدّمها للاعتماد؟ (بتاخد أيام)
3. **الفلوس:** المساعد مسموح يقول المصاريف وشروط التقسيط ولا يحوّل دايماً؟
4. **التحويل لزميل:** مين مسؤول يرد على المحادثات المحوّلة؟ وفي كام دقيقة؟
5. **تشغيل المساعد:** نبدأ على أرقام الموظفين كام أسبوع قبل الرقم الحقيقي؟
6. **البيانات الحساسة:** الرقم القومي والباسبور — مين بس يشوفهم؟
7. **الصفقات القديمة:** هندخّل كام صفقة شغالة دلوقتي، ومنين؟
8. **الترقيم:** `KA/2026/0001` مناسب ولا في نظام تاني؟
9. **الأسعار:** جدول المصاريف وحاسبة المقدم — امتى هيوصلوا؟ (من غيرهم مفيش عروض أسعار)
10. **mobile.de:** في حساب فعلاً؟ وبكام؟ (الأستاذ خالد)
