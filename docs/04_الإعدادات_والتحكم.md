# 4. الإعدادات والتحكم — كل مفتاح في السيستم

المفاتيح مرتّبة من **الأوسع أثراً** للأضيق. لو في تعارض، الأوسع بيكسب.

---

## 4.1 مفاتيح رسايل العملاء (أربع طبقات)

### الطبقة 1 — مفتاح عام يقفل كل الرسايل فوراً

**اسمه:** `car_import.stage_messages_enabled`
**مكانه:** Settings → Technical → Config Parameters
**القيمة:** `0` يقفل، وأي حاجة تانية (أو مفيش صف أصلاً) = مفتوح.

ده **زرار الطوارئ**. لو حصل أي لخبطة والعملاء بيوصلهم رسايل غلط، اقفله وخلاص —
مش محتاج نشر ولا restart، بيشتغل من اللحظة اللي بعدها.

### الطبقة 2 — مفتاح لكل مرحلة

**Configuration → Stages and messages → Notify customer**

دلوقتي **كل الـ14 مرحلة مقفولة**. ده الوضع الصح لحد ما:
1. الإدارة توافق على صياغة كل رسالة، و
2. واتساب يعتمد القوالب (بياخد أيام — ابدأ فيها بدري).

لما توافق، تقدر تفتحهم كلهم مرة واحدة بأمر واحد على السيرفر
(`seed_import_stages --enable-messages`) أو تفتح مرحلة مرحلة من الشاشة.

### الطبقة 3 — مفتاح لكل صفقة

**على فورم الصفقة: Hold customer messages**

لصفقة واحدة بالذات. استخدامه الأساسي: **يوم استيراد الصفقات القديمة**. لما
تدخّل صفقات شغالة من قبل السيستم، دخّلها والمفتاح ده مقفول، وبعدين افتحه صفقة
صفقة أول ما تتأكد إن العميل متابع — أول حركة مرحلة حقيقية بعدها تبقى أول رسالة
تلقائية توصله.

### الطبقة 4 — الإلغاء

الإلغاء **عمره ما بيبعت رسالة**، مهما كانت المفاتيح مفتوحة. قرار عمل، متحطوط
في الكود.

## 4.2 مفتاح الإفصاح عن الأرقام (مهم جداً)

**اسمه:** `car_import.ai_may_quote_published_fees`
**مكانه:** Settings → Technical → Config Parameters
**الوضع الحالي:** مفيش صف = **مقفول**

| الوضع | لما العميل يسأل "الرسوم بكام؟" |
|---|---|
| **مقفول** (دلوقتي) | المساعد **مبيقولش أي رقم** ويحوّل لزميل |
| مفتوح (`1`) | المساعد يقول الأرقام المعتمدة: أتعاب الشركة 4,750 يورو (أو 5,250 مع يورو 1)، الميناء والتخليص 55,000 جنيه، التوكيلات 300 دولار، خدمة الترخيص 3,000 جنيه — وبيفضل يرفض يقول تكلفة الرخصة نفسها |

**ليه ده مفتاح مش قرار في الكود؟** لأن الإدارة لسه ما ردّتش على سؤال "المساعد
مسموح يقول إيه عن الفلوس". لحد ما ترد، الوضع الآمن شغال.

**وليه اتحط في الأدوات مش في التعليمات؟** لأننا جرّبنا التعليمات وفشلت: لما
كانت التعليمات بتقول "حوّل لزميل" والأداة موجودة وبترجّع أرقام، الموديل استخدم
الأداة وقرأ قايمة الأسعار كلها للعميل. دلوقتي الأداة نفسها **مبترجّعش أرقام**
وهي مقفولة — وده اللي مينفعش يتفاوض عليه.

**اللي بيفضل ممنوع مهما كان المفتاح:** رقم حساب، تحويل، تأكيد وصول فلوس، خصم،
استرداد، إلغاء، أو حساب قيمة قسط معيّنة. دي كلها بتروح لزميل، دايماً.

## 4.3 مفاتيح المساعد الذكي

| المفتاح | مكانه | بيعمل إيه |
|---|---|---|
| **AI Auto-reply** | فوق يمين شاشة الشات | يقفل/يفتح المساعد على كل المحادثات |
| **handled_by_ai** | جوه المحادثة نفسها | محادثة واحدة بس |
| **Toggle AI** | زرار على فورم الصفقة | نفس الحاجة، من ناحية الصفقة |
| **ربط الرقم** | AI Studio → الحساب | ده اللي بيخلي المساعد يشتغل على رقم حقيقي أصلاً |

**دلوقتي:** الرقمين (Aya و Ramy Farahat) `handled_by_ai = False` والوركفلو
**مش مربوط بأي حساب**. يعني مفيش عميل حقيقي ممكن يوصله رد من المساعد.

---

## 4.4 مفاتيح الذكاء الاصطناعي والفلوس (الاشتراك)

| المفتاح | مكانه | بيعمل إيه |
|---|---|---|
| `ai.monthly_contact_limit` | Config Parameters | أقصى عدد محادثات في الشهر |
| `ai.paid_until` | Config Parameters | آخر يوم مدفوع |
| مفاتيح المزوّدين | AI Studio → Providers | مفتاح API لكل مزوّد |

> **تحذير:** لو الرصيد خلص أو التاريخ عدّى، المساعد **بيسكت من غير أي علامة في
> المحادثة**. مفيش رسالة خطأ للعميل ولا للموظف. اتأكد من ده **قبل** أي تجربة
> حقيقية، مش بعد ما تلاقي عملاء مستنيين.

**عن المفتاح الحالي:** النسخة دي شغالة دلوقتي بمفتاح **من السيرفر المركزي**
(بتاع الشركة الأم) عشان الاختبار. ده معناه إن الاستهلاك بيتحسب على حساب الشركة
الأم مش على حساب العميل. **قبل التشغيل الحقيقي لازم يتحط مفتاح العميل نفسه.**

## 4.5 الصلاحيات

**Settings → Groups** — الست مجموعات. الفكرة إن Sales Agent يشوف شغله، و
Management بس هي اللي تشوف البيانات الحساسة (الرقم القومي، الباسبور).

طريقة التأكد: اعمل مستخدم تجربة في مجموعة واحدة، ادخل بيه، وشوف الفرق.

---

## 4.6 خريطة سريعة: "عايز أعمل كذا" → "روح فين"

| عايز | الطريق |
|---|---|
| أقفل كل الرسايل دلوقتي حالاً | Config Parameter `car_import.stage_messages_enabled` = `0` |
| أغيّر نص رسالة مرحلة | Configuration → Stages and messages → افتح المرحلة |
| أمنع رسايل صفقة واحدة | الفورم → Hold customer messages |
| أخلي المساعد يقول الأسعار | Config Parameter `car_import.ai_may_quote_published_fees` = `1` |
| أقفل المساعد على محادثة | مفتاح AI جوه المحادثة، أو زرار Toggle AI على الصفقة |
| أقفل المساعد خالص | AI Auto-reply في الشات، أو فك ربط الوركفلو من الحساب |
| أغيّر أسلوب آية | ملف `prompts/voice_aya.md` ← يتعدّل ويترفع ويتعاد بناء الوركفلو |
| أضيف مرحلة جديدة | Configuration → Stages → Create (وخلي بالك من الترتيب) |
| أدي موظف صلاحية | Settings → Users → المجموعات |
| أعرف ليه رسالة ما وصلتش | Message log → افتح السطر → حالة الإرسال والخطأ |
| أغيّر نسبة المقدم أو المصاريف الإدارية | Configuration → **Pricing bands** → افتح الفئة |
| أغيّر مصاريف الشحن أو الميناء أو يورو 1 | Configuration → **Fee schedule** |
| أتأكد إن الحاسبة لسه بتطابق شيت العميل | `uv run python manage.py price_car --check` |
| أحسب عربية بسرعة من غير ما أعمل عرض | `uv run python manage.py price_car 48001 --eur1 --port port_said` |
